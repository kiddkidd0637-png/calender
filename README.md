# 我的學期一週時間表

這是一個零依賴的學期週時間表，可以直接在瀏覽器開啟 `index.html` 使用。

## 功能

- 星期一至星期日的橫向欄位，不顯示特定週日期
- 左側固定 11 個可編輯時間段（08:00 至 20:00，中午時段依原設定分隔）
- 可替每個時間段新增備註，例如標記 12:30 要處理的事情
- 點擊頁面大標，可直接修改標題
- 頁首標籤、說明文字、學期內容、日期範圍與操作提示都可以點擊編輯
- 點擊空白格子新增事件與備註
- 點擊已建立的事件，可直接修改標題與備註
- 按住已建立的事件卡片，可直接向上縮短或向下延長合併時段
- 拖曳同一天的連續空白格子，建立可跨多個時間段的事件
- 可刪除單一事件
- 事件與時間設定會依星期欄位自動儲存在瀏覽器，作為每週固定內容

## 使用

直接用瀏覽器開啟 `index.html` 即可。由於本專案不需要 Node.js 或套件安裝，不需執行額外的建置命令。
